## Personal AI Assistant Blueprint

The `docs/personal_ai_assistant.md` guide and the accompanying `src/personal_assistant.py` script show how to run a local coding-focused assistant that remembers your tasks and preferences. Start with the guide for setup options, then run `python src/personal_assistant.py chat` once you have a local LLM server running.

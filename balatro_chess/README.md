# Balatro Chess

A tiny chess variant spiced up with Balatro-inspired cards. Each turn, a player draws a card that can provide a one-shot power before moving.

## Cards
- **Extra Move** – take an additional move immediately.
- **Knight Shift** – move any one of your pieces as a knight for this move.

## Run
```bash
python balatro_chess.py       # interactive game
python balatro_chess.py --demo  # quick non-interactive demonstration
```
